# Fonts

All fonts are under the SIL Open Font License 1.1 (`OFL.txt`), licensed for commercial use and bundling.

- Montserrat (Julieta Ulanovsky et al.) — static ExtraBold (800) and Black (900) instances generated from the Google Fonts variable font.
- Noto Sans Arabic, Noto Sans JP (Google) — static ExtraBold instances for Arabic and Japanese captions.

Family names were made unique ("Montserrat ExtraBold", ...) so libass selects them unambiguously.
